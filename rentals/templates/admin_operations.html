Operational Flow

Follow the queue in order so every rental moves smoothly from payment to handover, return, and closure.

1. Ready For Handover

Start with paid confirmed bookings. Open the workflow, record handover details, and mark the rental as started.

2. Active Rentals

Monitor cars that are currently out with customers and move them to return inspection when they come back.

3. Returns Pending Closure

Complete return inspection, settle any extra charges, and only then close the booking.

4. Recently Completed

Review closed rentals to confirm the vehicle returned to the correct fleet state for the next trip.
